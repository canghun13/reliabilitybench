### Maximum-input regression and fix

The first stress run exposed a real rendering cost: an always-open multi-megabyte
report, especially a single JSON-escaped input line, delayed the browser.
This was corrected before deployment:

- Full report is now a native collapsed details section; inputs preserve their
  line breaks instead of becoming one escaped JSON line.
- Screen tables preview at most 200 rows; table cells over 480 characters are
  explicitly shortened, with the unabridged value retained in the report.
- At most 200 session detail blocks and 50 displayed findings per session;
  complete bounded findings remain available through Copy/report.
- Report opens for printing and restores its previous open/closed state after
  printing; editing invalidates and closes it.

Real-browser maximum runs after the fix:

- Filter: **240 IDs**, complete report; 200-row preview, no page overflow.
- DM1: **445 DTC records / 1,782 bytes**, complete report; preview bounded.
- BAM: **5,000 frames / 1,666 complete sessions**; report 709,592 characters,
  exact full Copy and Reset confirmed at 390 width; zero page overflow.
- Claims: **5,000 distinct NAME events**, 2,617,458-character report; explicit
  cell shortening, exact full Copy and Reset confirmed at 390 width; zero page
  overflow. These are synthetic limits tests, not user traffic.

### Print verification boundary

Current-result Print invokes the browser's native print path. In the in-app
browser this blocked the automated click command; no native preview surface was
exposed. The agent-owned print-test tab was closed. **Do not claim a visually
verified native PDF/print preview.** Report contents (title, URL, raw inputs,
units, current results, limitations), invalid-state gating and print-only CSS /
beforeprint/afterprint handling were inspected. The disclosure is opened for
valid printing; forms, interactive result panels and navigation are excluded.
No real printer job, PDF save or user settings change was performed.

This remaining preview limitation is recorded, not converted into a blanket
functional failure or a fabricated PASS. The tools are passive evidence aids;
no control-system or safety decision is automated.
