Mechanism first, factor second.

An acceleration factor is defensible only when the selected stress model represents the active failure mechanism and that mechanism does not change between use and accelerated conditions. Start with the model-selection guide, then use the formula reference to document symbols and limits.

These point calculations do not fit life distributions, estimate confidence bounds, set sample size, or prove a qualification requirement. Confirm material limits, competing mechanisms, stress interactions, and chamber capability before defining a test.
