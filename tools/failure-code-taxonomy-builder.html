Method

The builder trims blank entries, removes exact duplicates, limits each list to 20 values, and assigns simple draft codes. It deliberately does not create every problem-cause-remedy combination because many combinations would be invalid.

Release workflow

Define every value, pilot the lists on historical work orders, measure unknown and free-text use, merge ambiguous categories, and approve mappings before import. Preserve legacy codes for traceability.

Limitations

This is a taxonomy worksheet, not an ISO 14224 implementation, diagnostic system, or root-cause tool. Equipment-class detail and organization-specific code governance require accountable engineering review.
