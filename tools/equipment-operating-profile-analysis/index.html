Four independent questions.

The state analyzer interprets categorical changes; the load tool builds a time-at-load distribution; the excursion tool measures residence outside user-supplied limits; and the rate screen evaluates change per elapsed time. None diagnoses a fault, estimates remaining life, changes a control-system alarm, or authorizes operation.

Keep the source boundary visible.

Export timestamps with time zone and units, preserve missing-data flags, and record the active equipment mode and limit revision. A clean calculation cannot repair a logger gap, a stale sensor, or a limit applied to the wrong operating state.
