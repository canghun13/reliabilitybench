What this calculator does

Calculate an observed failure-rate point estimate from an event count and total exposure, or convert an already-known hourly rate, FIT value, or MTBF. The same rate is shown in all three rate units with its reciprocal interval. A FIT is one failure per billion device operating hours; it is a rate unit, not a failure probability.

When to use it

Use this for a fleet's observed failure rate or a transparent FIT-to-MTBF / MTBF-to-FIT unit conversion. For 100 devices operating 1,000 hours each, total exposure is 100,000 device-hours. Add the actual exposure for each device when hours differ. Keep the same population, operating conditions, period, and failure definition across inputs.

Inputs and formula

Observed mode uses a whole failure count and positive total device-hours. Known-rate mode uses a non-negative rate in the selected unit; MTBF mode uses a positive interval in hours. λ [h⁻¹] = failures / device-hours
FIT = λ × 10⁹
failures per 10⁶ device-hours = λ × 10⁶
reciprocal MTBF [h] = 1 / λ, for λ > 0

For a repairable population with the same scope, total exposure divided by failures is the observed MTBF. Interpreting the reciprocal as an exponential lifetime mean or using it in R(t) = exp(−λt) additionally requires a constant-rate model. This tool does not establish that assumption.

Worked example and interpretation

12 failures during 6,000 device-hours gives 0.002 failures per hour, 2,000 failures per million device-hours, 2,000,000 FIT, and a reciprocal interval of 500 hours. Separately, a known 250 FIT converts to 0.00000025 per hour, 0.25 per million device-hours, and 4,000,000 hours reciprocal MTBF. This long average is not a promised service life for any individual device.

Zero observed failures produces a zero point estimate, but no finite reciprocal MTBF can be estimated from that count. It does not prove zero risk or infinite life. A confidence bound needs a separately specified statistical model and confidence level, neither of which is calculated here.

Practical notes and limitations

Converting units does not turn observed data into a manufacturer prediction, add confidence, or correct for temperature, acceleration, duty, infant mortality, wear-out, seasonality, or common-cause failures. Preserve the source and conditions of a supplied FIT/MTBF value. Cycle-based rates cannot be converted to FIT without a justified hours-per-cycle relationship. This is not a safety-integrity, diagnostic-coverage, or qualification assessment.

Only the current calculated inputs and results appear in Copy/Print. Editing any input invalidates the report until recalculation. Very large or small positive values that cannot produce finite, non-zero conversions in browser arithmetic are rejected instead of displaying a false zero or unbounded number.
